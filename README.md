# KAD

KAD — небольшой VPN-сервис для закрытого круга пользователей. Пользовательский контур строится вокруг Telegram-бота и Mini App; backend хранит бизнес-состояние и управляет VPN-доступом через 3x-ui.

## Состояние проекта

Этап **Project Foundation завершён 2026-08-25**: GitHub принят как внешний источник правды, а базовая документация согласована и связана навигацией.

Следующий практический шаг — **read-only аудит VPS** по чек-листу из [runbooks](docs/runbooks/README.md). До него состояние живых компонентов считается ранее известным, но не подтверждённым заново. Последняя известная картина и точная точка продолжения находятся в [CURRENT.md](docs/CURRENT.md).

## Границы репозитория

Сейчас репозиторий содержит проектную документацию и историю решений. Он **не является** копией живого VPS и пока не содержит исходники backend, Telegram-бота или Mini App, production-конфигурацию, базу данных, резервные копии, ключи, токены либо пользовательские данные.

Живая инфраструктура не должна изменяться только ради приведения её к документации: сначала выполняется read-only аудит, затем расхождения фиксируются и планируются отдельно.

## Статусы фактов

- `VERIFIED` — проверено напрямую в указанном источнике и на указанную дату;
- `KNOWN` — подтверждалось ранее, но могло измениться;
- `NEEDS VERIFICATION` — требует проверки;
- `PLANNED` — запланировано, но не реализовано;
- `DECIDED` — принятое решение, действующее до осознанного пересмотра.

Секреты в публичный репозиторий не добавляются. Правило проекта: **public-first, secret-free**.
